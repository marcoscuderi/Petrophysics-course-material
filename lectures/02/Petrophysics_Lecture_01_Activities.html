Using this activity with the class

Open the matching activity when you reach the indicated slide. Ask students to predict before revealing results. Let a student select a value or suggest an experiment, change one input, and ask them to explain the response before showing the interpretation.

All plots and values are calculated from the displayed equations. They are model outputs, not experimental observations. The practice specimens are illustrative. No internet connection or installation is required. Tab through controls, use arrow keys on sliders, or type precise values into the number fields.
